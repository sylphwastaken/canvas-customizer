# Canvas Customizer

**Make Canvas work the way you want it to.**

Canvas Customizer is a free browser extension that improves the Canvas LMS experience with custom themes, flexible dashboards, assignment tracking, and Google Calendar integration.

Created and maintained by Sylph.

### Features

**Themes & Appearance**

- Built-in light and dark themes, including Gruvbox, OLED, Nord, and Catppuccin
- Animated themes featuring Snoopy, Tom & Jerry, and Garfield
- Create, save, import, and export custom themes
- Customize course colors, images, and interface elements

**Dashboard Customization**

- Move and resize course cards and widgets
- Rearrange courses and hide unnecessary items
- Customize course names and shortcuts
- Save layouts between browser sessions

**Assignments & Productivity**

- Improved To-Do list with weekly navigation
- Track upcoming, completed, and overdue assignments
- View course and semester progress
- Add personal notes, quick links, and schedule events

**Google Calendar Integration**

Canvas Customizer can synchronize Canvas assignments with Google Calendar.

When enabled, the extension creates a separate calendar named Canvas Due Dates. New assignments are added automatically, and existing events are updated when assignment details or deadlines change.

Synchronization occurs when the extension initializes on Canvas or when the user manually requests it.

Google Calendar integration is optional and requires authorization through your Google account.

**Additional Features**

- Advanced interface customization
- Support for over 60 languages
- Import and export settings
- Backup and restore customizations
- Responsive layouts for different screen sizes

### Privacy

Canvas Customizer stores customization preferences locally in your browser.

When Google Calendar synchronization is enabled, relevant course and assignment information is transferred to Google Calendar with your authorization.

Canvas Customizer does not sell user data or use it for advertising.

See the Privacy Policy for additional information.
