# Canvas Customizer

**Make Canvas work the way you want it to.**

Canvas Customizer is a free Chrome extension that improves Canvas LMS with custom themes, adjustable dashboards, assignment tracking, and Google Calendar integration.

### Features

- Light, dark, custom, and animated themes
- Movable and resizable dashboard widgets
- Course colors, names, images, and shortcuts
- Improved To-Do list with assignment tracking
- Google Calendar assignment synchronization
- Notes, schedules, and semester progress
- Backup and restore settings
- Support for over 60 languages

### Google Calendar Integration

Canvas Customizer can create a dedicated Google Calendar called **Canvas Due Dates**.

When enabled, the extension synchronizes Canvas assignments and updates existing events when deadlines or assignment details change.

Synchronization is optional and can be disconnected at any time.
